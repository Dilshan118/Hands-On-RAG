# Agent Behavioral Rules & Documentation Maintenance Protocol

## Documentation Synchronization Rule
Whenever creating a new feature, adding/modifying functions, updating agent node logic, changing dependencies, or making architectural decisions in this repository:
1. Always update **`README.md`** (Root portfolio landing page & Sub-project READMEs).
2. Always update **`AGENTIC_TUTORIAL.md`** (Technical tutorial & interview practice guide).
3. Always update **`SYSTEM_ENGINEERING_GUIDE.md`** (Senior AI Systems Engineering guide).

Ensure all three documentation files remain 100% synchronized with the active code implementation at all times.
